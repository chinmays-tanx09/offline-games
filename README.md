# Offline Games (Paradox)

An unofficial ad-free build of Offline Games (JindoBlu), packaged by Paradox. It installs as its own app (package `com.JindoBlu.OfflineGames.paradox`) next to the original.

**[Download the latest release](https://github.com/chinmays-tanx09/offline-games/releases/latest)** — get `Offline_Games_Paradox_v8.apk` from the Assets list and open it.

## Install

- Needs Android 6.0 or newer, arm64-v8a or armeabi-v7a.
- Updating: install the new APK over the old one. Official builds are all signed with the same key, so your data is kept.
- "App not installed"? You probably have a copy signed by someone else. Uninstall it first, then install the APK from this page.

## What's new in v3.15.3-p8
